# 🛒 Éxito Store - Prueba Técnica

Aplicación de comercio electrónico desarrollada.

Permite explorar productos, ver detalles, gestionar un carrito de compras y completar una compra ficticia.

---

## 🚀 Tecnologías utilizadas

- [React](https://reactjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Jest](https://jestjs.io/) + [Testing Library](https://testing-library.com/) (para pruebas)
- [FakeStoreAPI](https://fakestoreapi.com/) (API de productos)

---

## 📦 Instalación y ejecución local

1. Instala las dependencias:

```bash
npm install
```

2. Inicia el servidor de desarrollo:

```bash
npm run dev
```

3. Abre en el navegador:  
[http://localhost:5173](http://localhost:5173)

---

## 🧪 Ejecutar pruebas

```bash
npm test
```

Se incluyen pruebas básicas para `Header` y `ProductCard`.

---

## ✅ Funcionalidades implementadas

- Visualización de productos con búsqueda
- Página de detalle con rating y categoría
- Carrito con ajuste de cantidades y eliminación
- Página de pago con formulario y confirmación
- Estado global del carrito
- Pruebas unitarias básicas
- Estilo profesional y responsivo
